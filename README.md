# SYSTEM

Персональный трекер снижения веса в стилистике **Solo Leveling**: статусное окно охотника, уровни, XP, ранги, ежедневные задания и достижения.

Ноль зависимостей, ноль сборки, ноль сервера. Открыл `index.html` — работает.

---

## Запуск

**Вариант 1 — просто открыть файл**

Двойной клик по `index.html`. Всё работает, данные сохраняются в `localStorage` браузера.

**Вариант 2 — локальный сервер (нужен для PWA/офлайна)**

```powershell
python -m http.server 8080
```

затем открыть `http://localhost:8080`.

Рекомендуемый браузер: Chrome / Edge / Firefox (последние версии). На телефоне добавляется на домашний экран как приложение (PWA).

## Как считается

**Обмен энергией** — формула Миффлина–Сан Жеора.

```
муж:  10×вес + 6.25×рост − 5×возраст + 5
жен:  10×вес + 6.25×рост − 5×возраст − 161
```

**Калории цели** = TDEE ± поправка на режим, где 1 кг жира ≈ 7700 ккал.

```
сушка:      TDEE − rate × 7700 / 7
набор:      TDEE + rate × 7700 / 7
поддержание: TDEE
```

**Макросы**: белок 1,8–2,0 г/кг (при сушке и весе >110 кг — 1,9), жиры 0,8–1,0 г/кг, углеводы — остаток калорий. Нижний предел: 1400 ккал (муж) / 1200 ккал (жен).

**Вода**: 30 мл/кг с округлением до 50 мл.

**Тренд**: линейная регрессия по скользящему среднему за последние 7 точек, пересчитанная в кг/неделю.

**Калории тренировки**: MET × вес × часы.

**XP**: взвешивание 20, запись в дневник 15, тренировка 60, замеры 25, идеальный день 75, бонус за серию 50 → 2500.

**Ранги**: E → D → C → B → A → S → SS → SSS → SH (Тень) → MON (Монарх).

## Данные

Всё лежит в `localStorage` под ключом `system.solo.v1`. Никуда не отправляется. Раз в неделю делай резервную копию: **Система → Данные → Резервная копия (JSON)**.

Формат CSV (`Таблица (CSV)`) открывается в Excel / Google Sheets: вес, жир, обхваты, шаги, сон, калории (факт/норма), БЖУ, вода, тренировка.

Импорт JSON **полностью заменяет** текущие данные.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `1`…`7` | переключение разделов |
| `N` | новая запись веса |
| `F` | добавить еду |
| `W` | раздел тренировок |
| `Space` | отметить доступное задание дня |
| `Esc` | закрыть окно |

## Структура

```
index.html                 оболочка: HUD, сайдбар, модалки, порядок скриптов
manifest.webmanifest       PWA-манифест
sw.js                      сервис-воркер (офлайн-кэш статики)
assets/
  css/main.css             дизайн-система: цвета, панели, кнопки, HUD, окно статуса
  css/views.css            стили разделов
  img/icon.svg             иконка (+ maskable)
  js/data/food.js          DB_FOOD   — продукты, шаблоны, приёмы пищи
  js/data/exercises.js     DB_EX     — упражнения, планы, MET
  js/data/quests.js        DB_QUESTS — квесты и достижения
  js/core/util.js          U         — даты, числа, DOM, форматирование
  js/core/calc.js          C         — уровни, ранги, метаболизм, макросы, тренд
  js/core/store.js         Store     — состояние, XP, серии, квесты, достижения
  js/core/audio.js         SFX       — звуки на WebAudio без файлов
  js/core/ui.js            UI        — алерты, модалки, кольца, макросы
  js/core/chart.js         Chart     — графики на SVG
  js/core/fx.js            FX        — частицы повышения уровня
  js/views/*.js            разделы (render + mount)
  js/app.js                App       — роутер, HUD, онбординг, горячие клавиши
```

Порядок подключения важен: `data/*` → `core/util` → `core/calc` → `core/store` → остальное. Скрипты классические (без модулей), чтобы всё работало и с `file://`.

## Формулировки о точности

Расчёты — ориентир, а не медицинское предписание. Оценка состава тела по формуле Дьюренберг имеет погрешность ±4%. Всё, что ниже 1400 ккал для мужчин и 1200 ккал для женщин, система не предлагает. При болезнях, приёме лекарств или длительной сушке — согласуй нормы с врачом.
